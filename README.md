# distill-skill

从真实会话轨迹蒸馏可复用 skill 的工具链。

## 流程

```
取景 → 解析 → 抽六类信号 → 抽象 → 闸门分流 → 生成 → 校验 → 落盘
```

## 六类信号（对应 skill 部件）

```text
目标/成功判据 -> 什么叫做完
触发条件     -> description
动作序列     -> SOP 主体
决策点       -> 分支判断
坑与修正     -> 硬约束
可复用资产   -> scripts/assets
```

## 四条硬规则

```
压缩 delta，不压缩对话
特有值参数化，通用规律固化
单样本不注册，必须过评估门
只做 delta 追加，禁止重写
```

## 分流

```
多步可复用流程 -> 生成 skill
偏好/事实      -> 写 memory
一次性问答     -> 不沉淀
```

触发词：`沉淀成 skill` / `distill-skill`

## 使用

```bash
./install.sh
```
